■ 사용자 테스트 검증 결과 (실제 시나리오 12개)
───────────────────────────────────────────────────────────────────

Q1. "양하분 몇개 남았어"
  → ⏳ 양하 남은 작업: 8대 / 전체 10대 · 완료 2대 (20%)
  → 남은 컨 미리보기 10대

Q2. "지금 선적 18번 베이 몇개 들어갔지"
  → ✅ 18번 베이 선적 완료: 2대 / 전체 5대 (40%)
  → 남은 작업: 3대

Q3. "몇개 더 들어가야 돼"
  → ⏳ 전체 남은 작업: 11대 / 전체 15대 · 완료 4대 (27%)

Q4. "16번 베이 몇단 쌓았어"
  → 📊 16번 베이 단수
  → row별 단수: 최소 2 / 최대 5 / 평균 3.3단
  → 가장 높이 쌓인 tier: 84

Q5. "선적 완료 몇대"
  → ✅ 선적 완료: 2대 / 전체 5대 (40%)

Q6. "28번 베이에 몇개 실을 수 있어"
  → 📊 28번 베이 (40피트) 적재 분석
  → 현재 1대 / 관측 슬롯 1개 / 빈 슬롯 0개
  → 🔗 짝꿍 베이 27/29 합산: 현재 3 / 슬롯 3 / 빈 0

Q7. "홀드 바닥에 몇개 있어"
  → 📊 홀드 바닥: 3대 (Full 3 / 갑판 0 / 홀드 3)

Q8. "홀드 바닥에 몇개 남았어"
  → ⏳ 홀드 바닥 남은 작업: 1대 / 전체 3대 · 완료 2대 (67%)

Q9. "베이별 갯수"
  → 📊 전체 베이별 분포 (총 18대)
  → 16번: 10대 (F10/E0) ✅2
  → 18번: 5대 (F5/E0) ✅2
  → ...
