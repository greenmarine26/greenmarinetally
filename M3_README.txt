■ M3.5.4-fix2 변경사항

[1] 🐛 양하 화면 검정 에러 수정 (CRITICAL)
    원인: diagDismissed/diagAutoSpeak state가 잘못된 함수 안에 있어서
          ReferenceError → 전체 페이지 렌더링 실패
    수정: state를 메인 VoyagePage 컴포넌트로 이동
    효과: 양하 클릭하면 정상 진입

[2] 🔬 EDI=진실 원칙 강화 — 리퍼/X-RAY 카운트 정확화
    문제: 리스트(엑셀/PDF)가 EDI 리퍼 정보를 일반 컨으로 덮어씀
          → "리퍼 인데 40피트 일반 컨테이너로 분류"
    수정: EDI 핵심 필드(iso/rf/fr/ot/tk/dg/fe/bay/row/tier/pol/pod)는
          리스트가 절대 덮어쓰지 못하게 보호
          → 리스트는 sl(실번호)/wt(무게)/bl/sh/gi/op만 보강
    효과: 리퍼는 끝까지 리퍼로 분류

[3] 📝 X-RAY 카운트 정확화
    문제: xrayList의 메타필드를 컨번호로 잘못 카운트
    수정: 4자영문+7자숫자 정규식 검증 후 카운트
          평택 EDI 컨번호와만 비교

[4] 🔄 자료 업로드 중복 처리 옵션 ★
    EDI/리스트 재업로드 시 사용자 선택:
      1 = 교체 (기존 모두 삭제 후 새 것만)
      2 = 추가 병합 (중복은 새 값으로 덮어쓰기)
      3 = 신규만 추가 (중복은 기존 유지)
    효과: 항차 지웠다 다시 올릴 때 사고 방지

[5] ✏️ 컨테이너 규격(ISO) 직접 수정 ★
    실물이 EDI와 다를 때 검수원이 즉시 수정 가능
    예: EDI에 45GP인데 실제는 45RF → 클릭 한 번에 변경
    
    ContainerDetailModal에 [실물과 다름?] 버튼:
      - 13개 표준 ISO 옵션 (20DC/40DC/45HC/리퍼/플랫랙/오픈탑/탱크)
      - 선택 시 rf/fr/ot/tk 플래그 자동 갱신
      - 변경 이력 영구 저장 (검수자/시각/원본/변경값)

[6] ⚠️ 알 수 없는 ISO 자동 감지 ★
    EDI에 표준 아닌 규격 발견 시 경고
    🟡 "규격 확인 필요: N대 (표준 ISO 아님)"
    클릭 → 컨테이너 모달 즉시 열림 → 규격 수정

[7] 🔗 진단 경고 → 컨테이너 직접 수정 ★
    모든 진단 경고에서 컨번호 클릭 가능:
      - 리퍼 온도 미입력
      - 위험물 정보 누락
      - 무게 차이
      - 실번호 불일치
      - X-RAY 매칭 안됨
      - 알 수 없는 ISO
    클릭 → 컨테이너 모달 → 즉시 수정

■ 작동 흐름 (현장)

  검수원이 자료 업로드
      ↓
  자동 진단 실행
      ↓
  이상 발견 → 빨강/주황 점멸 패널 + 자동 음성
      ↓
  검수원이 경고 펼침 → 컨번호 목록
      ↓
  컨번호 탭 → 컨테이너 모달 자동 열림
      ↓
  실물 확인 후 수정 (실번호/규격/X-RAY 봉인 등)
      ↓
  변경 이력 자동 저장
      ↓
  진단 자동 재실행 → 경고 사라짐
