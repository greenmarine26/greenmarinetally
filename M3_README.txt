■ M3.0 핵심 변경 (이번 버전)
───────────────────────────────────────────────────────────────────

[1] AI 자유 질문 — 전체 데이터 컨텍스트 전달 (gemini.js)

  M2.x까지의 한계:
    - 검색 결과(matches) 30개만 AI에게 전달
    - "1번 베이 몇 대?", "베이 020 무게 합?" 같은 자유 질문에 답 못함
    - "대련에서 온 컨 몇대?" 같은 POL/POD 질문 답 못함

  M3.0 해결:
    ✅ allContainers 전체를 압축 형식(cn/p/iso/fe/m/wt/...)으로 전달
       → 토큰 절약 위해 약어 필드 사용
       → 최대 1500대까지 (4척 1000대 평균이므로 한 척은 모두 커버)
    ✅ 베이별 통계 미리 집계해서 전달
       (베이번호: {total/F/E/deck/hold/wt합계/rf/dg})
    ✅ POL/POD 분포 자동 집계 (선적항/양하항별 컨 수)
    ✅ 위험물(DG) 클래스별 집계 + 컨 리스트 별도 전달

[2] 항만/검수 도메인 지식 시스템 프롬프트 주입

  AI가 정확히 이해하도록 항만 용어를 시스템 프롬프트에 주입:
    ✅ 항구 코드 (KRPTK=평택, CNDLC=대련, CNQDG=청도, CNWEI=위해, ...)
    ✅ 컨테이너 ISO 규격 (22GP=20DC, 45RE=40HC RF, 42PC=40FR, ...)
    ✅ 상태 (F=Full, E=Empty)
    ✅ 위치 (BBBRRTT, DECK≥80, HOLD<80)
    ✅ 무게 (TARE/NET/GROSS/VGM)
    ✅ 특수화물 (RF/DG/FR/OT/TK/OOG)
    ✅ 검수 워크플로 (양하/선적/시프팅/봉인/실오류/TWIN/X-RAY)
    ✅ 다단계 적재 (FR 4개 한 자리 등)

[3] IMDG 위험물 격리표 주입

  AI가 위험물 트윈 가부를 판단할 수 있도록:
    ✅ 9개 클래스 (1=폭발물 ~ 9=기타위험물)
    ✅ 격리 등급 (Away from / Separated from / 격실 분리 / 수평 격실 분리)
    ✅ 트윈/인접 적재 가부 판단 원칙
       (예: Class 3 + Class 5 = Separated → 트윈 불가)

  사용자 예시 질문:
    "위험물 3/1234와 2/1234 트윈 가능?" → IMDG 격리 기반 답변
    (단, "정확한 판단은 IMDG Code 격리표 확인 필요" 안내 추가)

[4] 선박 라이브러리 (M2.6) 컨텍스트 활용

  ✅ 항차 IMO로 선박 라이브러리 자동 로드 (VoyagePage)
  ✅ AI에게 이전 항차 평균(양하/선적/총항차수) 전달
     → "이 선박 평소 양하 몇 대?" 같은 질문 답변 가능

[5] AI 답변 품질 개선

  ✅ temperature 0.3 → 0.2 (더 일관된 답변)
  ✅ maxOutputTokens 300 → 600 (베이별/리스트 답변 위해)
  ✅ 답변 규칙 강화:
     - "데이터에 없으면 추측 금지, '데이터에 없음' 답변"
     - "위치는 베이-row-tier 형식 (예: 020-04-84)"
     - "위험물 트윈 가부는 IMDG 격리 등급으로 판단"

■ 테스트 시나리오 (M3.0 검증)
───────────────────────────────────────────────────────────────────

이전엔 답 못하던 질문들 — 이제 답 가능해야 함:

  Q1) "1번 베이 몇 대?"
      → 베이별 통계에서 즉답 가능

  Q2) "020 베이 무게 합 얼마야?"
      → 베이별 wt 합계 사용

  Q3) "대련(CNDLC)에서 온 컨 몇 대?"
      → POL 분포 사용

  Q4) "청도행 컨 위치 알려줘"
      → POD=CNQDG 필터링

  Q5) "위험물 클래스 3 컨 몇 대 어디?"
      → DG 클래스별 + 리스트 사용

  Q6) "리퍼 영하 25도 컨 위치"
      → 전체 리스트에서 tmp 필터

  Q7) "DECK에 있는 Empty 몇 대?"
      → tier≥80 + fe='E' 필터

  Q8) "이 선박 평소 양하 몇 대?"
      → 선박 라이브러리 평균 사용

  Q9) "위험물 3/1234와 2/1234 트윈 가능?"
      → IMDG 격리표 판단 + 안내문
