■ M3.2 핵심 변경 (이번 버전)
───────────────────────────────────────────────────────────────────

[문제 인식 — M3.0 테스트 결과]
  AI(Gemini)에 1500대 컨테이너 데이터 + 통계를 통째로 던지면
  Gemini가 정확히 계산을 못함.
  - 토큰이 너무 많음 (1000대 ≈ 60K 토큰)
  - JSON 파싱 + 한국어 계산을 동시에 해야 해서 실패
  - 베이별/POL별/구역별 질문에 답변 못함

[해결 전략 변경]
  AI 의존을 줄이고 → JS가 직접 답할 수 있는 건 다 직접 답변
  AI는 정말 분류 안 되는 자유 질문 fallback만

[1] nlSearch.js 대폭 확장 — 새 패턴 6개 추가
  ✅ 베이 번호: "16번 베이", "베이 16", "1번 베이", "100번 베이"
  ✅ 한국어 항구명 50+ → POL/POD 코드 매핑
     평택, 인천, 부산, 광양, 대련, 청도, 위해, 상해, 천진, 닝보,
     도쿄, 요코하마, 카오슝, 싱가포르, LA, 뉴욕, 함부르크 등
  ✅ POL/POD 구분: "대련에서/발/출발" vs "청도행/가는/도착"
  ✅ 구역: "갑판"(tier≥80) vs "창내/선창"(tier<80)
  ✅ 위험물 클래스: "클래스 3", "DG class 9", "3급"
  ✅ UN 번호: "UN1234", "유엔 3082"
  ✅ 무게 조건: "20톤 이상", "10톤 이하"
  ✅ 양하/선적 모드 키워드
  ✅ 위치/리스트 의도: "어디", "위치", "리스트", "보여줘"
  ✅ 무게 합계: "무게 합", "총중량"

[2] 로컬 답변 생성기 (generateLocalAnswer)
  AI 호출 없이 parsed 결과로 한국어 답변 직접 생성
  ✅ 베이별 통계 답변 (총수/F·E/갑판·창내/총중량/특수)
  ✅ 무게 합계 + 컨별 무게 리스트
  ✅ 위치 리스트 (POL/POD/DG/UN/온도/구역 등 강한 조건)
  ✅ 통계 + 세부 (Full/Empty, 양하/선적, 갑판/창내 분포)

[3] 검색 결과 종류 정리
  🟡 BigResultCard      — 단일 컨테이너 (4자리 검색)
  🔵 통계 카드          — "몇 대" 단순 카운트 (시안색)
  🟢 즉답 카드 (M3.2)   — 베이/항구/구역/무게 (에메랄드색)
  🟣 AI 카드            — 진짜 자유 질문 (보라색)

[4] 인앱 매뉴얼 (HelpModal.jsx)
  ✅ 헤더에 도움말 ? 버튼 추가
  ✅ 검색창 우측에 "예시" 미니 링크 추가
  ✅ 9개 카테고리 탭: 기본 / 개수 / 베이 / 항구 / 특수화물 /
                       음성 / AI 질문 / 트윈 / 팁
  ✅ 100+ 실제 사용 예시 (질문 → 답변 매핑)
  ✅ 모바일/데스크톱 반응형

[5] 음성 안내 보강
  ✅ 로컬 답변 첫 두 줄 자동 음성 (좌표는 M3.1 한국어화 자동 적용)

[6] 버그 수정
  ✅ "20피트 풀 몇대" → "20"이 컨번호로 잡히던 문제 해결
  ✅ "20톤 이상" → 동일 해결
  ✅ "대련발 양하" → POL/POD 둘 다 CNDLC로 잡히던 충돌 해결

■ AI는 언제 쓰나 (M3.2)
───────────────────────────────────────────────────────────────────

  쓰는 경우 (검수원이 AI 버튼 명시적으로 누를 때만):
   - 정말 자유로운 질문
   - "이 선박 평소 양하 몇 대?" (선박 라이브러리)
   - "위험물 3/1234와 5/2468 트윈 가능?" (IMDG 격리)
   - "검수 마무리 조언"

  안 쓰는 경우 (즉답으로 처리):
   - 통계 ("몇 대")
   - 베이/항구/구역/무게/온도/UN 등 정형 질문
   - 컨번호 검색
   - 특수화물 위치

→ 결과: AI 호출 빈도 90% 감소, 정확도 100% (JS 계산이라)
