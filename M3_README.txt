■ 오늘 부족했던 것 모두 보완

[1] EDI 000 온도 → 미입력 처리 (utils.js)
    - EDI에 13개의 "TMP+2+000:CEL" 발견 → 진짜 0도 아니라 미입력 표기
    - 검수원이 "0°C"로 오인하는 것 방지
    - tmp_missing 플래그로 명시
    - 엑셀 파서도 동일 적용

[2] 자동 진단 시스템 (diagnostics.js 신규)
    🔴 critical:
      - 리퍼 온도 미입력
      - 위험물 클래스/UN 누락
      - IMDG 격리 위반 의심
    🟡 warning:
      - EDI vs 리스트 카운트 차이
      - 무게 차이 (1톤 이상)
    🔵 info:
      - 실번호 불일치
      - X-RAY 매칭 안됨

[3] 자동 음성 + 경고등 + 점멸 (DiagnosticsPanel.jsx 신규)
    - 자료 업로드 후 자동 음성 (한 번)
    - critical: 빨강 점멸 + 음성
    - warning: 주황 + 음성
    - info: 파랑 (음성 X)
    - 음성 ON/OFF 토글
    - 경고 닫기 버튼

[4] 리퍼 처리 규칙 C (사용자 결정)
    - BigResultCard: 온도 미입력 리퍼 빨강 점멸 강조
    - "리퍼 · 온도 미입력 ⚠️" 빨강 배지 + 점멸
    - 실 달린 리퍼는 무조건 리퍼 리스트 포함

[5] 베이플랜 리퍼 시각 강조 (BayPlan.jsx)
    - 시안색 두꺼운 ring (배경색 평택/통과 그대로)
    - 우측 상단 ❄ 아이콘
    - 온도 미입력 시 ❗ 빨강 점멸 추가
    - 셀 안 텍스트: 온도 있으면 "-18C", 없으면 "⚠NO TEMP" 빨강 점멸

[6] CSV 내보내기 (CSVExport.jsx)
    - "온도미입력" 컬럼 신규 추가
    - 미입력 시 "⚠️미입력" 표시
    - 수석/관리자 보고서에 활용

[7] 자동 진단 호출 (VoyagePage.jsx)
    - 모든 탭 위에 진단 패널 자동 표시
    - 평택 양하/선적만 필터링 후 비교
    - autoSpeak 토글 + dismissed state

■ 음성 출력 예시 (실제 EDI 검증)

  실제 KSKM2608NCNXMNB.edi (504대, 평택 양하 123대):

  [리스트 없음 + 리퍼 8대 중 1대 온도 미입력]
  → "리퍼 8대 중 1대 온도 미입력입니다. 현장 확인 필요"

  [가짜 리스트 50대 추가, 무게 다 다름]
  → "리퍼 8대 중 1대 온도 미입력입니다. 현장 확인 필요.
     CMA EDI 123개인데 리스트는 50개입니다. 73개 부족합니다.
     리스트 보완 필요.
     무게 차이 49건 발생. 확인 필요"

  → 검수원이 다른 작업 중에도 귀로 들어옴
