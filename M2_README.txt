【M1.10 → M2.0 변경】

✅ 1. Gemini AI 자유 자연어 (NEW!)
   - 키 발급된 Gemini 2.0 Flash 연동
   - 검색창에 자유 질문 입력 후 [✨ AI에게 물어보기] 버튼
   - 항차 데이터 컨텍스트 자동 전달
   - 예시 질문:
     "이 항차 검수 진행률 어때?"
     "FA선사 컨테이너 평균 무게는?"
     "베이 010에 리퍼 온도 정상이야?"
     "특이사항 요약해줘"
     "왜 010 베이에 컨이 없어?"
   - 답변은 화면 표시 + 음성 안내
   - 무료 할당량: 분당 15 / 일 1500 (충분)

✅ 2. 트윈 자동 짝꿍 (NEW!)
   - 앞 컨번호 입력 → 짝꿍 자동 추천
   - 알고리즘 (어제 EDI 분석 결과):
     * 짝수 베이 = 40ft / 홀수 베이 = 20ft
     * 트윈 = 같은 row+tier에 인접 홀수 베이의 컨
     * 예: 005-02-04 → 003-02-04 또는 007-02-04 자동
   - 짝꿍 못 찾거나 다르면 [수동 입력] 가능
   - 양쪽 카드 동시 표시 + 각자 [✓ 검수 완료] 버튼
   - 둘 다 완료되면 검색창 자동 비워짐 → 다음 트럭 바로 받기

✅ 3. 카드 직접 완료 + 자동 비우기 (UX 개선)
   - 결과 카드에 [✓ 검수 완료] 버튼 직접 추가
   - 모달 안 열어도 완료 가능
   - 완료 후 검색창 자동 비워짐 → 다음 컨 바로 입력
   - 모달은 상세 보기/수정 시에만 사용

✅ 4. 리퍼 온도 = Full만 표시 (수정)
   - 기존: F/E 무관 표시 (M1.8 잘못 변경)
   - 복원: Full + 리퍼 + 온도 있을 때만 큰 뱃지 표시
   - Empty 리퍼는 "리퍼 (Empty)" 작은 뱃지

✅ 5. 베이플랜 폰 기본 30%
   - 폰 진입 시 30% 자동 (한 베이 전체 보임)
   - 줌 단계 0.1로 세밀 (10%씩 조절)
   - 줌 최소 30% / 최대 300%
   - "기본 배율" 버튼 = 폰 30% / PC 100%로 복귀

✅ 6. 뒤로가기 막기 + 종료 버튼 (NEW!)
   - 폰 뒤로가기 → 앱 안에서 페이지 이동만
   - 홈에서 뒤로가기 → 앱 종료 안 됨 (홈에 머무름)
   - 헤더 우측에 [⏻ 종료 버튼] 추가 (빨강)
   - 명시적 종료 버튼으로만 종료

✅ 7. 검색 정확도 (M1.10 유지 + 강화)
   - 4자리 입력 → 끝4자리 정확 일치만
   - 2~3자리 → 끝쪽 매칭만 (3480 ≠ 다른 컨 실번호)
   - FR/OT는 ISO 코드 기반 자동 매칭
     * 46P3 = 45FR (이번 항차에 4개 있었음)
     * 42PC = 40FR
