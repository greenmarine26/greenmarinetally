【M1 → M1.1 변경 사항】
1. ✅ 통합 검색 — 모든 항차·양/선적 한 검색창에서 (홈 → "통합 검색" 버튼)
2. ✅ 입체 베이플랜 — DECK/HOLD 분리, 색상 코드, 줌, 깊이감
3. ✅ 검수 보고서 — 시간순/검수원별 그룹 (보고서 탭)
4. ✅ 수석 대시보드 — 5명 진행률 + 전체 통계 (홈 → "수석 대시보드")
5. ✅ 컨테이너 상세 카드 — 카드 클릭 시 상세 모달 (모든 정보 + 액션)
6. ✅ 통계 항목 풍부 — 규격/F·E/특수화물(RF·FR·OT·TK·DG)/검수업체별 (통계 탭)
7. ✅ 음성 지원 — 한 글자씩 한국어, 검색·완료시 자동 (예: "일·사·공·이")

【탭 구조】
홈 화면
├── 통합 검색 (모든 항차)
├── 수석 대시보드 (5명·통계)
└── 항차 카드 → 클릭
    └── 항차 상세
        ├── 양하/선적 (모드 토글, 둘 다 있을 때)
        └── 6개 탭:
            • 양하/선적 — 컨테이너 리스트, 검증, CSV
            • 검색 — 4자리 자동 음성
            • 베이 — 입체 베이플랜
            • 통계 — 규격·F/E·특수·선사
            • 보고서 — 누가/언제 검수
            • 자료 — EDI·엑셀·X-RAY 업로드

【베이플랜 색상 의미】
🟦 파랑/주황 = 평택 미완 (양하/선적 모드별)
🟢 초록 = 검수 완료
🟣 보라 = X-RAY 대상
🔵 하늘 = 리퍼 (RF)
🔴 빨강 = 위험물 (DG)
⬜ 회색 = 통과/타지역
✕ 회색 X = 40피트 컨테이너 점유

【음성 출력】
- 자동: 검색에서 4자리 정확 매칭 시 (한 글자씩)
- 수동: 검색창 우측 음성 버튼
- 완료: 컨테이너 검수 완료 시 "○○○○ 완료"
- 한국어 발음: 0=공, 1=일, 2=이, ... 9=구
- 영문: A=에이, B=비, C=씨, ...

【사용 흐름 (수석 검수원)】
1. 홈 → "수석 대시보드" → 5명 진행률 한 번에
2. 부족한 검수원/항차 발견 → 항차 카드 클릭 → 상세 확인

【사용 흐름 (현장 검수원)】
1. 홈 → 항차 카드 → "검색" 탭
2. 4자리 입력 → 음성 자동 출력
3. 카드 클릭 → 상세 모달 → "검수 완료" 버튼
4. 베이 탭에서 진행도 확인
