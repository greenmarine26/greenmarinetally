【배포 후 처음 1번만 할 일】
1. PC 크롬에서 사이트 접속
2. F12 → Application → Service Workers → 옛 SW 모두 Unregister
3. F12 → Application → Storage → Clear site data
4. Ctrl+Shift+R
→ 이후부터는 자동 업데이트, 수동 작업 불필요
