【M1.1 → M1.2 핵심 추가】
✅ 실번호 원본 보관 (sl_orig 필드, 절대 변경 X)
✅ 실번호 수정 이력 (누가/언제/무엇)
✅ X-RAY 세관봉인 + 전자봉인 인라인 편집 (V37 동등)
✅ X-RAY 봉인 원본 보관 + 수정 이력
✅ 컨테이너 카드에 "원본 → 실제" 시각적 표시 (다르면 빨강)
✅ "실오류" 뱃지 자동 표시
✅ 보고서 탭에 "🚨 실오류 신고" 섹션 추가
✅ 세관 신고용 별도 CSV (실오류만 추출)
✅ 세관 신고용 텍스트 복사 버튼 (1클릭)
✅ CSV에 원본·실제·수정자·시각 컬럼 추가

【실오류 워크플로】
1. 항차 작업 중 — 실번호/X-RAY봉인 다르면 카드 클릭 → 모달에서 수정
2. 시스템 자동: 원본 보존 + 새 값 저장 + 이력 기록
3. 카드에 자동으로 빨강 "실오류" 뱃지 표시
4. 항차 끝나면 → 보고서 탭 → "실오류 신고" 토글
5. "텍스트 복사" 또는 "실오류 CSV" 버튼 → 세관 신고

【세관 신고 양식 예시】
원실번호 1234567 → 실제 2341567
원봉인 X12345 → 실제 X54321

【데이터 구조】
records/{cn}/sl_orig         원본 (엑셀에서 받은 값)
records/{cn}/sl              현장 실제 값 (수정 가능)
records/{cn}/sl_history      수정 이력 [{from,to,by,at}]

xraySeals/{cn}/seal_orig     원본 세관봉인
xraySeals/{cn}/seal          실제 세관봉인
xraySeals/{cn}/eseal_orig    원본 전자봉인
xraySeals/{cn}/eseal         실제 전자봉인
xraySeals/{cn}/history       수정 이력
