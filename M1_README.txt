【M1.4 → M1.5 핵심 변경 (사용자 지적 4건)】

✅ 1. 검색 범위 좁힘 (가장 중요!)
   문제: "3480" 입력 시 컨번호엔 없는데 실번호에서 매칭돼서
         엉뚱한 컨테이너 보여줌
   해결: 검색은 컨번호 + 끝4자리만!
        실번호/베이/검수업체/B/L 검색 안 함
   → "3480" → 컨번호 끝4자리가 3480인 것만, 없으면 "컨테이너 없음"

✅ 2. 베이플랜 전체 세로 스크롤 모드 복원 (V37처럼)
   - 컨트롤 바에 "✓ 전체 세로" 토글 (기본 ON)
   - 모든 베이를 1번부터 끝까지 위→아래로 스크롤
   - 베이 점프 드롭다운: 클릭 시 해당 베이로 자동 스크롤
   - "단일 페이지" 클릭하면 ◀▶ 페이지 모드도 가능

✅ 3. 트윈 모드 (음성 X)
   - 싱글/트윈 토글
   - 싱글: 검색창 1개, 음성 OK
   - 트윈: 검색창 2개 (앞/뒤), 음성 비활성 (오류 방지)
   - 트윈 비교: 같은 베이/검수업체/F/E 자동 검증

✅ 4. 결과 카드 표시 우선순위 (검수 핵심)
   1순위: 실번호 거대 (text-5xl) + 노랑 반짝임
          실오류 시 빨강 + 더 강한 반짝임 + 원본/실제 표시
   2순위: X-RAY 대상 → 큰 보라 박스 + 반짝임
          (세관봉인 + 전자봉인 함께 표시)
   3순위: 특수화물 → 컬러 뱃지 (RF온도/DG/FR/OT/TK)

✅ 5. 음성 안내 간결화
   - 컨번호 + 실번호 + X-RAY 만!
   - 위치/모드/검수업체 등 안 읽음
   - 예: "삼사팔영, 실번호 일이삼사오육칠, 엑스레이"
   - 컨번호 없을 때: "삼사팔영, 컨테이너 없음"

【검수 워크플로 핵심】

[싱글 작업 (트럭 1대 = 컨 1개)]
1. 트럭 도착 → 컨번호 끝 4자리 부른다 (예: "3480")
2. 폰 마이크 누르고 "삼사팔영" 또는 키보드 입력
3. 카드 표시:
   ┌──────────────────────────┐
   │ [양하] 3480 OOCU8493480 │
   │                            │
   │   실번호 (Seal No)         │
   │   ████████ ← 거대,반짝임   │
   │                            │
   │ [🔍 X-RAY 대상] (있으면)   │
   │ [❄ RF 25°C] (특수화물)    │
   │                            │
   │ 010-01-04 · 40HC · F       │
   └──────────────────────────┘
4. 음성: "삼사팔영, 실번호 ○○○○○○, 엑스레이"
5. 트럭의 실번호와 화면 실번호 대조 → 일치하면 OK

[트윈 작업 (트럭 1대 = 컨 2개)]
1. 트럭 도착 → 앞/뒤 컨번호 끝4자리
2. 키보드로 위 검색창에 앞 번호, 아래 검색창에 뒤 번호
3. 두 카드가 위아래 표시됨
4. 자동 비교: 같은 베이? 같은 검수업체? F/E 같음?
5. 두 카드의 실번호 모두 트럭과 대조
