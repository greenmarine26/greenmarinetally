【M1.5 → M1.6: F/E 풀/엠티 구분 정확도 강화】

✅ 문제: 양하 리스트 엑셀에서 풀/엠티 구분이 틀림
✅ 원인: 선사마다 SIZE/TYPE/F/E 컬럼 구조가 다른데
        지금까지는 F/E 컬럼만 보거나 TYPE만 봐서 누락 발생

✅ 해결: 4단계 우선순위로 종합 판정

   1순위: 명시적 F/E 컬럼
          - "F" / "E"
          - "FULL" / "EMPTY"
          - "L" / "MT" / "M"
          - "LOADED"
          - "적공" / "적/공"

   2순위: TYPE 컬럼 끝 글자 (V37 ASC 패턴)
          - "20DCF" → F
          - "40HCE" → E
          - "22GPF" → F
          - "DCHC035F" → F
          - "DC20030E" → E

   3순위: SIZE 컬럼 끝 글자
          - "20F" → F
          - "40E" → E
          - "20FT-F" → F

   4순위: 무게 기반 추정 (현장 실측)
          - 20피트 ≤ 2.5톤 → Empty
          - 40피트 ≤ 4.5톤 → Empty
          - > 5톤 → Full

✅ 추가: 헤더 인식 강화
   - SIZE 컬럼 별도 인식 (이전엔 TYPE에 합쳐져 있었음)
   - 헤더명 "size", "sz", "len", "사이즈", "규격" 모두 매칭
   - TYPE 헤더에서 'size'를 제외해서 두 컬럼이 같이 있어도
     각각 별도로 잡힘

✅ 카드 표시 개선
   - F/E 미정(빈 값) 시: 노랑 ⚠? 표시 (디버그용)
   - F: 진한 초록 뱃지
   - E: 회색 뱃지
   - 한눈에 미인식 컨테이너 식별 가능

✅ 카운트 로직 명확화
   - 이전: c.fe !== 'F' → empty (빈 값도 empty로 잘못 카운트)
   - 변경: c.fe === 'F' → full / 'E' → empty / 빈 값 → 미카운트

【테스트 방법】

1. 양하 리스트 엑셀 업로드
2. 양하 탭에서 카드들의 F/E 뱃지 확인:
   - 초록 F = Full ✓
   - 회색 E = Empty ✓
   - 노랑 ⚠? = F/E 못 잡음 (보고 부탁드립니다)
3. 필터에서 "F (적컨) N" "E (공컨) M" 카운트 확인
4. 노랑 ⚠? 가 보이면 어떤 컨테이너인지, 어떤 양식의 엑셀인지
   알려주시면 헤더 인식 추가 가능

✅ 해결: GlobalSearchPage도 SearchPanel과 동일하게

   - 알파벳 포함 → + 선박명 추가 (항차 찾기 용도)

✅ 음성도 간결화 (M1.5와 동일):
   - 컨번호 + 실번호 + X-RAY만
   - 예: "사칠칠, 컨테이너 없음"

==================================================
  M1.8 — 🤖 AI 자연어 검색 + 리퍼 온도 표시 강화
==================================================

✅ 1. AI 자연어 검색 (singlemode 강화)

   기존: 4자리 숫자만 검색
   M1.8: 사이즈/F/E/특수화물/끝4자리 조합 검색

   예시:
   - "40피트 4777"     → 40피트 컨 중에 끝4자리 4777
   - "20 엠티"          → 20피트 공컨 모두
   - "리퍼 4777"        → 리퍼이고 끝4자리 4777
   - "40피트 풀"        → 40피트 적컨 모두
   - "위험물"           → DG 컨테이너 모두

✅ 2. AI 통계 답변 ("몇 개" 질의)

   질의 인식: "몇 개", "몇 대", "얼마나", "총 몇" 등
   답변: 큰 숫자 카드로 표시 + 음성 안내

   예시:
   - "리퍼 몇 개?"        → "리퍼 N대" (큰 숫자)
   - "40피트 풀 몇 개?"   → "40피트 풀 K대"
   - "엑스레이 몇 대?"    → "X-RAY 대상 M대"
   - "20피트 엠티 몇 개?" → "20피트 엠티 J대"
   - "위험물 몇 개?"      → "DG L대"

✅ 3. 인식 결과 표시 (투명성)

   검색창 아래에 "🤖 인식: 40피트 끝4자리 4777" 표시
   → AI가 어떻게 이해했는지 명확히 보임
   → 잘못 이해했으면 사용자가 즉시 알 수 있음

✅ 4. 리퍼 온도 표시 강화

   기존 문제: 리퍼인데 온도 표시 안 됨
   원인: F/E 못 잡은 컨은 온도 뱃지 안 보임 (조건 너무 엄격)
   해결: F/E 무관, 리퍼 + 온도 있으면 항상 큰 뱃지

   - 리퍼 + 온도: ❄ RF 25°C (큰 뱃지)
   - 리퍼만: ❄ 리퍼 (작은 뱃지)

✅ 5. SmallResultCard 정보 추가
   - 사이즈 (40HC 등)
   - F/E (정확한 색상 - 미정 시 노랑 ?)
   - 리퍼 온도 (❄25°)
   - DG (🔥)

【인식 가능 키워드】

사이즈: 20피트, 40피트, 45피트, 20ft, 40ft, 40HC
F/E: 풀, 적컨, full, loaded / 엠티, empty, 공컨
리퍼: 리퍼, reefer, 냉장, 냉동, RF

【사용 시나리오】

[트럭 도착 — 빠른 확인]

       음성: "사칠칠칠, 실번호 ○○○○○○○, 엑스레이"

       음성: "리퍼 12대"

  M1.9 — AI 답변 정확도 개선

✅ 문제: 일부 키워드 인식 실패
   - "FR 몇개야"   → "전체 0개" (틀림, 정답: 0개)
   - "TK 몇 개야"  → "전체 0개" (틀림)
   - "OT 몇 개야"  → "전체 0개" (틀림)
   - "컨테이너 몇 개야" → "전체 0개" (틀림, 정답: 전체 N대)

✅ 원인:
   - 정규식이 ^fr$ 식으로 단독 단어만 매칭
   - "FR 몇개야"의 "fr"는 단독이 아니라 매칭 안 됨
   - "컨테이너" 키워드 처리 없음

✅ 해결:
   - 단어 경계 \b 사용 → "FR 몇개야"의 "fr"도 매칭
   - "컨테이너", "전체", "all" 키워드 추가 → 전체 질의
   - OOG 키워드 추가
   - F/E 정규식에서 \bfull\b, \bempty\b 사용

【M1.9에서 정확히 작동하는 질의】

==================================================
  M1.10 — 통합 검색에도 AI 자연어 적용
==================================================

✅ 문제: 홈 → 통합 검색은 컨번호만 인식, 자연어 인식 안 됨
✅ 원인: SearchPanel만 AI 적용, GlobalSearchPage 누락
✅ 해결: GlobalSearchPage에도 동일한 AI 자연어 적용

【통합 검색에서도 가능】
- "리퍼 몇 개야?"      → 모든 항차 리퍼 합계
- "40피트 풀 몇 개?"   → 모든 항차의 40피트 풀 합계
- "X-RAY 몇 개?"        → 모든 양하 X-RAY 합계
- "DG 몇 개?"           → 모든 DG 합계
- "엠티 몇 대?"         → 모든 엠티 합계
- "컨테이너 몇 개?"     → 전체 항차 합계

【싱글 검색 vs 통합 검색】
- 싱글: 한 항차 안에서만 (양/선적 합쳐서)
- 통합: 모든 항차 + 양/선적 모두

같은 자연어 처리, 같은 음성 안내, 같은 UI.
