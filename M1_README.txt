【M1.3 → M1.4 핵심 변경】

✅ 1. 검색 통합 (양/선적 한 번에)
    - 양하/선적 탭 따로 검색 X
    - 항차 안에서 양/선적 모두 한 검색창에서
    - 결과 카드에 [양하][선적] 뱃지로 구분
    - 검색 탭 라벨에 🎤 표시

✅ 2. 음성 검색 (V37 100% 이식)
    - 한국어 음성 인식 (Web Speech API)
    - "공구일오" 식으로 또박또박 → 자동 검색
    - 한 템포 빠르게 (interimResults: true)
    - 인식 중 transcript 실시간 표시
    - Gemini API 안 씀 (V37 검토 결과 Web Speech만 사용)

✅ 3. 자동 음성 안내 (V37 동등)
    - 1개 일치 → 전체 안내 (컨번호+위치+실번호+모드)
    - 2~5개 → 첫 번째 결과 안내
    - 6+ → "더 자세한 번호" 권장
    - 0개 → "일치 없음, 다시 말씀하세요"
    - 음성 끄기 토글 (스피커 아이콘)

【사용 방법】

1. 항차 진입 → "검색 🎤" 탭
2. 마이크 아이콘 (주황) 클릭
3. "공구일오" 또는 "1402" 또는 알파벳 식으로 또박또박
4. 자동으로 검색됨 → 결과 1개면 음성으로 위치까지 안내
5. 결과 카드 클릭 → 상세 모달

【홈에서도 가능】
홈 → "통합 검색" 버튼 → 모든 항차·양/선적 한 번에

【키보드 입력도 가능】
마이크 누르기 싫으면 그냥 키보드로 4자리 → 동일하게 음성 안내
