깔고 나면 주소창 없는 전체 화면으로 열립니다. 아래 안내는 지금 쓰시는 폰에 맞춰 나옵니다.

지금 카카오톡·네이버 같은 앱 안 브라우저로 열려 있습니다. 여기서는 설치가 끝까지 안 됩니다. 크롬으로 다시 열기

버튼이 안 먹으면 주소를 복사해서 크롬(아이폰은 사파리)에 붙여 넣으세요.

아이폰은 사파리에서만 전체 화면 앱으로 설치됩니다. 지금은 다른 브라우저입니다.

복사한 뒤 사파리를 열어 주소창에 붙여 넣고 이 페이지를 다시 여세요.

평택검수 앱

방법 1 · 앱 설치 (권장)

  1. 아래 검수앱 열기를 누릅니다.
  2. 크롬은 오른쪽 위 ⋮ → 앱 설치 (또는 홈 화면에 추가 뒤 설치)를 누릅니다. 「바로가기」가 아니라 「설치」여야 주소창이 없습니다.
  3. 삼성 인터넷은 아래 ≡ → 현재 페이지 추가 → 홈 화면을 누릅니다.
검수앱 열기

방법 2 · APK 파일로 설치 (방법 1이 안 될 때)

  1. 아래 APK 받기를 누릅니다.
  2. 받기가 끝나면 알림이나 「내 파일 → 다운로드」에서 파일을 열고 설치를 누릅니다.
  3. 「출처를 알 수 없는 앱」 허용 창이 뜨면 허용 뒤 다시 설치를 누릅니다.
APK 받기 (검수앱)

받기 막대가 끝까지 찼는데 「받는 중」에서 안 끝나면 3분만 기다린 뒤 방법 1로 하세요.

  1. 아래 검수앱 열기를 누릅니다. (사파리)
  2. 아래 가운데 공유 버튼(□↑)을 누릅니다.
  3. 목록을 올려 홈 화면에 추가를 누르고 오른쪽 위 추가를 누릅니다.
  4. 홈 화면의 아이콘으로 열면 주소창 없는 전체 화면입니다.
